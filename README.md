# 🛡️ Stackly — Business Insurance Web Project

A modern, fully responsive **Business Insurance** web application built from a Figma design. Features a sleek dark UI, animated components, user/admin dashboards, and full multi-page navigation.

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Flexbox, Grid, Glassmorphism
- **Vanilla JavaScript** — Animations, interactions, auth logic
- **GSAP** — Advanced scroll & entrance animations
- **AOS** — Animate On Scroll library
- **Font Awesome 6** — Icons
- **Google Fonts (Inter)** — Typography
